# Personal Portfolio — Next.js

A modern developer portfolio built with Next.js and Tailwind CSS, with content managed through a Strapi headless CMS.

## 🚀 Live Website

[View My Portfolio](https://irfanapv.netlify.app/)

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- JavaScript
- Tailwind CSS
- HTML5

### Backend / CMS
- Strapi
- REST API

### Database
- PostgreSQL 


### Deployment
- Netlify — Frontend
- Render — Strapi CMS

### Tools
- Git
- GitHub
- VS Code

## ✨ Features

- Responsive developer portfolio
- Dynamic content managed through Strapi CMS
- Projects and portfolio information fetched through REST API
- Responsive design for desktop and mobile
- Modern Next.js frontend
- Separate frontend and CMS deployment

## 🏗️ Architecture

```text
Next.js Frontend
       |
       | REST API
       ↓
   Strapi CMS
       |
       ↓
    Database
